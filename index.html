The Full Story: From Personal Pain Point to 10K Monthly Conversions

One of the projects I’m particularly proud of was a mobile widget I led at Bitso, designed to improve asset discoverability and price awareness across our listed crypto assets.

The initial motivation came from a user pain point I personally experienced as a Bitso user. I felt there was an opportunity to make asset prices more accessible and localized for our LatAm users, allowing them to track relevant market information at a glance.

I took ownership of the initiative from the product definition stage. I created the PRD in Confluence, documenting the user pain points, expected usage, technical requirements, and monitoring strategy. Once aligned with my PM, I created a Figma prototype and benchmarked similar experiences across other platforms. I then worked with our designer to validate the UI direction before starting development.

From an engineering perspective, I led the implementation across backend and mobile. On the backend side, I worked with the existing architecture and identified an opportunity to create a lightweight version of our larger crypto-tab data flow. I implemented dedicated business endpoints for searching and consuming assets, aggregating asset information, localized prices, metadata, and historical graph points.

This was particularly interesting because it was my first time implementing backend code within Bitso. I collaborated with four backend engineers, who helped explain the existing architecture and validate the new endpoints. The mobile-to-backend communication was REST, while gRPC was used internally between backend services.

Once the backend infrastructure and API contracts were established, I implemented the iOS interface using SwiftUI and a lightweight branch of our internal networking layer. I also wanted to make sure we could deliver across both mobile platforms. I defined the frontend architecture and coordinated the Android implementation with two Android engineers, while another iOS engineer helped with code reviews and testing. I maintained alignment across API contracts, UI variations, and analytics instrumentation.

After shipping to production, I created Amplitude dashboards to track adoption and conversion funnels, alongside DataDog dashboards and alerts to monitor backend health and incidents. I also coordinated with our marketing team to promote the feature and increase awareness among Bitso users.

The result was approximately 10,000 transactions generated through this widget entry point during its first month in production.

"What I particularly enjoyed about this project was that I wasn’t limited to implementing an assigned ticket. I identified the opportunity, defined the product, expanded beyond my original iOS specialization into backend development, coordinated cross-platform delivery, and ultimately measured the business impact."

Automated AI Cross-Stack Debugging & Slack Diagnostics

As our engineering team shifted toward AI-assisted development, our backend engineers started interacting directly with staging mobile builds, and mobile engineers with staging backend APIs. To streamline cross-stack debugging, I built an internal AI-Driven Network Monitor into our app's debug menu.

The tool features an automated diagnostic flow: when an API call fails, it automatically redacts sensitive data (like tokens, keys, and authorization headers) before packaging the sanitized payload, HTTP status, and app state into a standardized context.

It then passes this context alongside relevant repository code to our internal AI agent. The AI analyzes the failure (identifying root causes like expired Signadot keys, environment mismatches, or schema/DTO mismatches between mobile and backend) and instantly posts a clear diagnosis directly to the engineer's Slack.

It turned multi-hour cross-team debugging sessions into instant, self-service resolutions.
